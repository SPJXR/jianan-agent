# ADR-006：法规时效的检索侧降权（草案/已废止不得作为第一依据）

- 状态：已接受（Accepted）
- 日期：2026-10-11
- 关联：ADR-002（条件补充混合检索）、ADR-005（表格感知分块）、`docs/PRD.md §11`、`kb/docs_meta.json`

## 背景与问题

2026-10-11 用真实问题做端到端验证时发现：问"有限空间作业前需要检测哪些气体"，**首条引用来自 0070《房屋市政工程有限空间识别及施工安全作业指南（征求意见稿）》**。

征求意见稿不是生效规范。在一个面向安全员现场决策的工具里，把草案排在第一位作为依据，属于内容准确性缺陷；而该工具的核心承诺恰恰是"每条结论可溯源、不可编造"。

根因分两层：

1. **数据层**：`kb/docs_meta.json` 中 34 份文档的 `valid_status` 全部为空（DB 默认 `unknown`），检索层无法区分正式稿、试行稿与征求意见稿。
2. **算法层**：`hybrid_search` 的弱命中分支把向量 top-k **直接置于结果前列**（`fused = list(vec_hits)`），该分支完全不查看文档时效；BM25 主路径也没有任何时效因子。

## 决策

1. **检索层引入时效乘性降权**，系数集中在 `retrieval.VALIDITY_PENALTY`：
   - `repealed` → ×0.35
   - `draft` → ×0.60
   - **`unknown` / `effective` / 空值 → ×1.0（一律不降权）**
2. **降权位置在所有加分项之后**（覆盖率、bm25 bonus、整句命中、标题命中都算完再乘），保证它是纯粹的"依据资格"调整，不与相关性信号相互缠绕。
3. **向量路单独补一道稳定分区** `_validity_partition()`：向量命中仍置前，但已核定为草案/已废止的被整体压到末尾，其余相对次序不变。这是必要的——只在 `search()` 里降权挡不住向量路。
4. **降权不是过滤**：草案与已废止条款仍可被检索到、仍会展示，只是不占第一依据位。
5. **引用契约新增 `validStatus` 字段**，前端在**引用来源卡片**与**知识库来源抽屉**两处用同一套徽章口径（`validityBadge()`）显示"现行有效／已废止／试行·征求意见稿／时效待确认"。

## 关键取舍：为什么 `unknown` 不降权

这是本决策最重要的一条，也是最容易被"顺手改严"的一条。

当前 34 份文档**全部**是 `unknown`。若把 `unknown` 也纳入降权：

- 等于让"还没核定"直接变成"检索质量下降"，所有排序同时塌陷重排，**ADR-002 用 POC 实验换来的"强命中零回归"结论当场失效**；
- 且会给出错误激励——为了让指标好看而草率填写时效状态。

因此本决策要求：**时效处理只在文档被明确核定为草案或已废止时生效**；未核定的走原排序，并在界面上如实显示"时效待确认"。数据层的空白由核查工作（回填 `valid_status`）解决，不由算法层掩盖。

## 后果

- 正面：草案/已废止不再充当第一依据；用户与评审都能在界面上直接看到依据的时效状态；核查工作与算法行为解耦，可分别推进。
- 已知边界：**降权系数 0.35 / 0.60 是经验值，未经真实双盲评测标定**。目前只保证"方向正确 + 不改变未核定语料的排序"，不宣称数值最优。待 34 份时效状态回填完成后，应结合分层问题集重新评估是否需要调参或改为硬性重排。
- 待办：`kb/docs_meta.json` 的 `valid_status` 与 `version_date` 仍待逐份核定（**优先 0069 与 0070**，二者是同一指南的试行版与征求意见稿）。

## 验证

`tests/validity_test.py`（7 个用例，纯标准库，`python -m unittest tests.validity_test -v`）：

| 用例 | 守卫的性质 |
|---|---|
| `test_only_draft_and_repealed_are_demoted` | 只有草案/已废止被降权，`unknown`/`effective`/空值系数恒为 1.0 |
| `test_case_insensitive` | 大小写与首尾空格不影响判定 |
| `test_demoted_goes_last_and_order_is_stable` | 降权项被稳定压到末尾，其余相对次序不变 |
| `test_noop_when_all_unverified` | 全未核定时该函数是恒等变换 |
| `test_no_document_is_demoted_today` | 当前索引确实没有任何文档被核定为草案/已废止 |
| `test_bm25_ranking_unchanged_by_penalty_code` | **零回归**：开关降权字典后 BM25 排序逐位相同 |
| `test_draft_is_pushed_down` | 在临时库副本上把全部文档标为草案，检索仍返回结果（降权非过滤、不抛错） |

## 遵循

- `app/retrieval.py`：`VALIDITY_PENALTY` / `_validity_factor()` / `_validity_partition()`；`SQL_CAND` 与 LIKE 召回 SELECT 增列 `d.valid_status`
- `app/vector_search.py`：`top_k()` 的 SELECT 增列 `d.valid_status`
- `app/main.py`：`_sources_payload()` 增加 `validStatus`
- `web/app.js`：`validityBadge()`，引用卡片与来源抽屉共用
