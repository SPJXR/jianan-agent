# ADR-011: 反馈台账与提示词段计数（ACE 启示落地）

## Status: Accepted (2026-11-12)

## Background

论文精读（docs/research/论文精读-ACE-ICLR2026-20261111.md）指出两个工程痛点与解法：

1. **P3+**：GOV-06 跨日漂移、VAL-02 拒答格式抖动的归因此前靠人肉「复测 3 次 +
   A/B 探针」——ACE 的 bullet 计数器设计（helpful/harmful 累计，单次噪声不决定
   去留）提示应把抖动治理机制化；
2. **P2+**：ACE 的上下文演化依赖可靠机械反馈。本系统已有在线可机判信号
   （[n] 引用白名单），但它只随答案流走、不留存——应落盘成为反馈发生器。

## Decision

### 1. 在线反馈台账（app/feedback.py，main.py 四个终态点接线）

- 每次问答落一行 `data/feedback_ledger.jsonl`（gitignored 运行时数据）：
  `ts / qhash / qlen / role / backend / coverage / n_sources /
  feats{validity, adjacent, rewrite_attempted, rewrite_merged} /
  citations / cite_bad / answer_chars`；
- **合规口径与 app/track.py（PRD §11）一致：只存问题哈希与长度，不存原文**、
  不存用户身份；评测题可由题面哈希回连（tools/segment_ledger.py §四），
  普通用户问题不可逆推；
- **best-effort**：落盘异常吞掉打日志，绝不影响问答主链路（track.py 同款）；
- SSE 对外契约零改动（自检不进事件流）；段口径与 3.3（ADR-006 词表）、
  3.1（ADR-005 增补断裂检测）同源，不另起炉灶。

### 2. 段计数台账（tools/segment_ledger.py）

- 对评测集逐题**确定性**复算段特征（今日检索、原问题路径、装配逻辑镜像
  main.py；弱命中改写不模拟，rewrite_would 单列不参与判定）；
- 聚合历史 eval JSON 输出：段在场/缺席通过率对比 + 结果翻转三分类——
  **A 段归因候选**（活跃段集合变化，需 A/B 探针终审）、**B 漂移候选**
  （段集合相同，优先怀疑 LLM 服务端漂移）、C 稳定；
- run 规格带「该 run 服务端实际启用的段」：`ctx-24:validity;ctx-31:validity,adjacent`
  ——历史跑分时代码里未必有该段，这是跨版本对比的基础。

## Consequences

- 正面：首份台账（docs/eval/段计数台账-20261112.md）即自动复现 11-07 的
  人肉归因（PM-06/PM-11 adjacent 归因），并多抓出一例 EDGE-05（adjacent=1
  的边界翻转，人眼对比当时遗漏）；在线/离线特征在冒烟题上完全一致
  （PM-06 adjacent=1 双源吻合）；GOV-06 不误报（其 citation 翻转非 ok 翻转）。
- 边界：工具只提线索不定罪——A 桶候选仍需 A/B 探针终审（GOV-06 教训写进
  报告头部）；离线特征是原问题路径近似，弱命中 14 题单列声明。
- 成本：每问一次 JSONL 追加（微秒级），无 LLM 额外调用。
- 红线重申（ACE 精读 §3.6）：台账是**反馈基础设施**，不是提示词自动演化的
  许可证——契约规则/时效状态/拒答判据永不进演化空间；不对 62 题分数做
  提示词搜索（评测是守卫不是训练集）。

## 增补（2026-11-13）：RECOMP 启示落地——错误复制率指标 + 压缩设计红线

### 1. 新增评测维度：copy_rate（证据无关时错误复制率）

RECOMP（ICLR 2024）实测：证据不含答案时，完整 Top-5 上下文让模型 **81%**
仍从证据复制答案。落地为拒答/边界组的新指标：

- `classify_answer`（app/feedback.py 纯函数，run_eval 与 tools/copy_rate.py
  同源调用）：copy = 带 [n] 引用 ∧ 无拒答标记 ∧ 无缺席承认措辞；
- **误报防线**：copy_review 桶——带引用但明说「未列出/未包含」并引用佐证的
  合理行为不计入 copy。设计依据是真实案例：ctx-24 EDGE-05 答案（承认未列出
  指标数值 + 引用 [9][3] 佐证）曾被初版指标误判为 copy，复核后改为 review 桶
  并补单测（tests/feedback_ledger_test.py 16/16）；
- 首轮实测（ctx-24 / ctx-31，各 8 道拒答/边界题）：**copy_rate 0/8 / 0/8**——
  本系统的诚实拒答契约 + 边界纪律下未出现 RECOMP 式错误复制，该指标转为
  **常驻守卫**（run_eval 汇总新增 copy_rate / copy_review / refusal_with_cite）；
- 附带收益：拒答形态明细（带引用/长度）让 GOV-06 类拒答格式漂移自动显形
  （ctx-24 GOV-06 164 字带引用 ↔ ctx-31 裸拒答 36 字）。

### 2. 压缩设计红线（RECOMP §2.2 登记）

若未来长文档场景需要上下文压缩：**只许 extractive 选句、引用仍指向原文块、
必须过 verify_verbatim 逐字校验；abstractive 摘要禁止进入引用链**（RECOMP
实测 HotpotQA 33% 摘要完全不忠实，法规条款一个数字漂移即错误答案）。
本系统当前规模不引入压缩器：62 题训练样本不足（RECOMP 需 4 万+）、P95<800ms
无压缩器预算、9k tokens 实测非瓶颈——三重证据，不因论文改变既有决策。
