> **用途**：对 v5（角色化提示词）及后续版本做质量评测，量化「检索命中 + 答案要点覆盖 + 引用规范 + 诚实拒答」四项指标，为论文④「角色化收益」提供数据基线。

## 二、评分规则（自动打分约定）

1. **检索分**：top3 命中「预期来源」任一文档记 1 分。0069（试行）与 0070（征求意见稿）为同一指南两版本，命中任一均算过。
2. **关键词分**：JSON 中 `keywords` 为二维数组，内层是同义词组（如 `["30min","30分钟"]`），任一同义命中即该项命中；**全部命中 = 要点覆盖达标**，命中过半 = 部分分。
3. **引用分**：回答含 `[1]`、`[2]` 样式编号记 1 分（refusal 类不要求）。
4. **拒答分**（refusal 类）：出现「未找到」或「本助手仅提供建安法规知识问答」且未编造具体条款数字即 PASS。
5. **边界分**（boundary 类）：回答须明确知识库未收录该内容（或仅有标准名称）；出现编造的具体数值/条款即 FAIL，转人工复核。
6. **角色风味**：不做自动打分，抽样对照见附录 A。
