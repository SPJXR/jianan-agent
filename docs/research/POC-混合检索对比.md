# POC：混合检索（BM25 + 向量）方案对比报告

- 日期：2026-09-22
- 背景：OPEN-DECISIONS 第一在决项（混合检索向量方案选型）；依据车蕾论文（LoRA+RAG 协同优化）模块③检索增强思路，为 V3 的 BM25 单路引入向量检索
- 范围：向量检索 + 双路融合；神经重排（Bce-reranker）明确留待下一轮
- 实验脚本：`tests/poc_hybrid.py`（四方案主对比）、`tests/poc_sim_distribution.py`（库内外可分性）、`tests/poc_weight_grid.py`（加权融合定标）、`tests/poc_conditional.py`（最终方案验证）

## 一、实验设置

- **语料**：422 片段（avg 481 字），chunk_id 与 kb.sqlite 对齐
- **向量模型**：BAAI/bge-small-zh-v1.5（512 维，92MB）、BAAI/bge-large-zh-v1.5（1024 维，1.3GB）
- **编码方式**：不对称编码——查询侧加前缀「为这个句子生成表示以用于检索相关文章：」，语料侧不加；向量归一化后余弦检索
- **索引**：`kb/vec_index_<model>.npz`（`tools/build_vec_index.py` 产出）
- **评测集**：qa_regression 的 14 题（A 组 10 核心题 + C 组 4 口语题），标注「问题 → 预期文档」；B 组 5 题库外题观察误召回
- **指标**：top-1 / top-3 命中率、MRR；B 组观察 top1 相似度分布

## 二、四方案主对比（tests/poc_hybrid.py）

| 方案 | top-1 | top-3 | MRR | 未命中题 |
|------|-------|-------|-----|---------|
| BM25(基线) | 71.4% | 85.7% | 0.792 | C1 |
| VEC-small 单路 | **78.6%** | **100.0%** | **0.893** | - |
| VEC-large 单路 | 57.1% | 78.6% | 0.699 | C4 |
| RRF(BM25+small) k=60 | 64.3% | 92.9% | 0.788 | - |
| RRF(BM25+large) k=60 | 71.4% | 100.0% | 0.845 | - |

关键观察：

1. **VEC-small 单路最强**：top-1 +7.2pp、top-3 +14.3pp、MRR +0.101，对 BM25 的天花板（C1 口语题字面不匹配）有实质突破。
2. **bge-large 显著劣于 bge-small**（top-1 -21.5pp）：语料仅 422 片段、领域高度垂直，large 通用语义空间的区分优势无从发挥，反而引入噪声。small 同时具备体积（92MB vs 1.3GB）与延迟（CPU 单次编码 5ms）优势，**线上模型选定 bge-small-zh-v1.5**。
3. **朴素 RRF 融合劣化**（small 融合 top-1 反降 7.1pp 至 64.3%）：BM25 已调优的排序被向量路「平均」掉，强命中题（A 组精确条款查询）被拖累。

## 三、补充实验

### 3.1 库内外相似度可分性（tests/poc_sim_distribution.py）

| 集合 | top1 相似度 |
|------|------------|
| 库内 14 题 | min=0.493，mean=0.657 |
| 库外 B 组 5 题 | max=0.605，mean=0.535 |

结论：两分布**重叠（0.493 ~ 0.605）**，不存在能同时保住库内召回、拦下库外误召回的单一向量相似度阈值。B 组兜底不能改由向量阈值承担。

### 3.2 B 组误召回观察

small 对 B 组 top1 相似度 0.481 ~ 0.605（如 B1 食堂证照 → 0074 误命中 0.605），均落在库内题的正常区间内。同时 B 组 BM25 覆盖率也不低（B1=0.75）——**现状的兜底实际依赖生成层（LLM 按引用诚实作答 + 时效标注），而非检索阈值单方面**。因此兜底链路维持不变：覆盖率仍按 BM25 主路计算。

### 3.3 加权融合网格（tests/poc_weight_grid.py）

score = BM25 分 + VEC_W × cos 相似度，VEC_W = 0~8 全网格：top-1 全部 64.3%，无一优于基线。与 RRF 结论互相印证：**任何打破 BM25 已调优全序的「均匀融合」都劣化**。

## 四、最终方案：条件补充（tests/poc_conditional.py）

融合不作用于排序全序，只作用于**弱命中分支**：

- **强命中（max coverage ≥ 0.5，现状不再触发改写的题）**：完全走 BM25 原排序，向量路不参与——精确条款号/术语题零回归风险，覆盖率、兜底、改写逻辑全部不变。
- **弱命中（max coverage < 0.5，原本就走改写重检的场景）**：向量 top-5 置前 + BM25 top-3 追加，供改写后重检与生成引用。

验证结果：

| 方案 | top-1 | top-3 | MRR | 分支分布 |
|------|-------|-------|-----|---------|
| 条件补充 | **78.6%** | **100.0%** | 0.881 | strong 11 / weak 3 |
| BM25 基线 | 71.4% | 85.7% | 0.792 | - |
| VEC-small 单路 | 78.6% | 100.0% | 0.893 | - |

- top-1 / top-3 与向量单路持平，MRR 仅低 0.012（C3 口语题由 OK@1 变 OK@2）
- 相对基线：top-1 +7.2pp、top-3 +14.3pp、MRR +0.089
- 强命中 11 题（含全部 A 组精确查询）与 BM25 逐题一致，**零回归**
- C1（原唯一未命中题）由弱命中向量路救回 OK@1

## 五、结论与决策

| 决策点 | 结论 |
|--------|------|
| 线上向量模型 | **bge-small-zh-v1.5**（large 召回劣化 + 体积 14 倍 + CPU 延迟劣势，淘汰） |
| 融合方式 | **条件补充**（强命中 BM25 原排序 / 弱命中向量置前），否决朴素 RRF 与加权融合 |
| 兜底判据 | 维持 BM25 覆盖率主判据，不引入向量阈值（库内外重叠不可分） |
| 部署形态 | bge-small ONNX int8 量化（服务器无 GPU，CPU 编码约 5ms/次，量化后预计更低） |
| 回滚开关 | HYBRID=off 秒级降级回 BM25 单路 |

决策记录见 `docs/decisions/ADR-002-混合检索条件补充方案.md`。

## 六、对原计划的偏离说明

计划（A方向混合检索升级）原定 RRF 融合（k=60 各取 top10）。POC 数据显示 RRF 与加权融合在本语料上均劣化（§二.3、§3.3），遂改为条件补充方案并在 §四 验证达标。偏离理由与证据如上，已在 ADR-002 中正式记录。神经重排（Bce-reranker）维持原计划，留待下一轮评估。
