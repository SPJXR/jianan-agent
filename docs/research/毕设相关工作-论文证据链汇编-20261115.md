## 二、评测口径四篇对照（论证「规则断言」的取舍）

| 论文 | 主指标 | 已知局限 | 我们的选择 |
|---|---|---|---|
| ALCE | NLI（TRUE/T5-11B）判蕴含 | kappa recall 0.698 / precision 0.525；测不了部分支持 | 规则断言（逐字/编号白名单/关键词组）：**更严、零模型依赖、零跨日漂移** |
| Mem0 | LLM-as-a-Judge（10 次运行均值±标准差） | judge 随机性、需多次平均 | 同上；GOV-06 漂移实证说明 LLM 指标的抖动面 |
| A-MEM | F1 / BLEU-1 | ALCE/Mem0 均证词面重叠会放过事实错误（March vs July） | 同上；用拒答组与逐字引用补词面盲区 |
| 项目 | 62 题规则断言三合一套闸（检索命中∧覆盖∧引用） | 语义覆盖窄、测不了改写式支持（ALCE 抽检补位） | 可复现性 > 语义覆盖度的显式取舍 |

**可写进论文的论点**：「规则断言先于 NLI/LLM judge」不是工程妥协，而是面向「条款逐字可核查」场景的选择——法规问答里一个数字漂移即错误答案，宁可拒答/人工复核，也不要一个会漂移的语义裁判。

## 三、四条多重证据链（每个「不做」至少两篇论文背书）

1. **不压缩**：RECOMP 机械截断伤 86% 被引块（自测） + LongLLMLingua 熵压缩低于 zero-shot + 9k tokens 非压力区自测 + A-MEM/Mem0 的 token 成本动机不适用本项目。
2. **诚实拒答不可被增强替代**：RECOMP 证据无答案时 81% 错误复制 → LongLLMLingua 开卷分心（ClosedBook 正确性反高） → **A-MEM adversarial F1 50.03 低于基线 69.23**（更强组织更会挤出答案）；本项目用 MIN_COVERAGE 兜底 + 拒答组 5/5 + 弃答路径审计（硬答 0）守住。
3. **更多上下文不是更好**：RECOMP Top-1 PPL 32.90 vs Top-5 35.53 → LongLLMLingua 片段饱和（ChatGPT top-3 后饱和） → A-MEM k=10→50 平台/略降；本项目 14 块窗口、PER_DOC_CAP、2.2 POC 三次同向。
4. **不让 LLM 重写累积知识**：ACE 的 collapse 突变（18K→122） + **A-MEM 记忆演化 = LLM 物理改写替换旧笔记**（组织质量受底座模型影响，§6 局限①）；本项目 ADR/OPEN「只追加 + 人工 Curator + 逐字节守卫」。

## 五、章节骨架建议（写作时按此展开）

1. **问题陈述**：法规问答的「不可靠回答有严重后果」→ 引伊斯兰问答同构对标（ACL 2026 Findings）+ 综述局限性(1)「知识库缺信息时生成看似合理错误回答」→ 立论：诚实拒答 + 逐字引用是一等公民。
2. **相关工作**：按 §一 矩阵分四族（上下文演化 / 压缩 / 引用评测 / 记忆），每族给出「前沿结论 → 为何在本场景不适用或如何工程化」。
3. **方法**：10 个 ADR × 综述分类学映射（见 RAG 三篇分析 §二 A 表）；ADR-011 反馈台账作为「演化纪律 + 观测先行」的实现。
4. **实验与评测**：62 题规则断言（§二 取舍论证） + §四 六项自有实证 + 四次 POC 否决（说明「无实测失败不施工」的方法论）。
5. **讨论/局限**：词面口径的必要非充分（ALCE/F1 误判互证）、9k tokens 无压力区的规模边界、LLM 跨日漂移（GOV-06）与规则断言的零漂移优势。
