## 一、论文要解决的问题（与我们的问题高度同构）

排污许可证技术规范文件「信息密集、结构复杂」，从业人员检索条款低效；通用大模型直接迁移会幻觉。→ **换成「建安法规 34 份文档、施工安全从业者查条款慢、通用 AI 编造条款号」，就是我们的 PRD 问题陈述**。这是典型的「传统行业垂直知识问答」研究，方法论可迁移。

## 二、核心框架 LR-DP（四大模块）

```
① 问答数据集构建 → ② LoRA 微调（L-DP）→ ③ 融合 RAG（LR-DP）→ ④ 角色化提示词增强
```

### 模块①：基于 ChatGPT4 辅助标注的问答数据集构建

- 原始语料采集：按行业分类名录整理 78 份排污许可文件
- 数据清洗流水线：格式转换 → 文本清洗（去噪）→ 规范化 → 过滤 → 去重
- **问答对生成三步法**：聚类分组 → ChatGPT4 按提示词模板分组生成问答对 → 人工精细化标注难例
- **数据增强**：SEQGAN 生成法（分布相似的新答案）+ 替换法（词/短语替换），增强后**双重校验**（正则匹配 + 术语表约束关键条文/数值，再人工复核）
- 产出：1869 条问答样本（1308 训练 / 561 验证）

### 模块②：LoRA 微调（L-DP）

- 基线模型：ChatGLM3-6b、ChatGLM4-9b、Qwen2.5-7b、Qwen2.5-14b、Baichuan2-13b
- LoRA 原理：冻结基模型权重，仅在部分参数子空间引入低秩可训练矩阵，微调后低秩矩阵与基模型权重求和
- 工具：LlamaFactory；超参：200 epoch、lr=5e-5、bfloat16、截断 2048、batch 2×8 累积
- 硬件：2×V100 64Gib

### 模块③：RAG 集成（LR-DP，7 步）

1. 语料转换 → 2. 中文递归文本分割 → 3. **Bge-large-zh-v1.5 生成嵌入向量** → 4. 向量数据库（键值对存储） → 5. 用户问题同样用 Bge 向量化 → 6. 余弦相似度检索 → 7. L-DP 基于问题 + 高相似片段生成回答
- **检索增强两策略**（重点，与我们直接相关）：
  - **查询重写**：剔除「限额」「排污许可证」等高频干扰词——这类词在向量相似度搜索中造成偏向，掩盖问题中的其他关键信息
  - **结果重排**：召回 20 条 → **Bce-reranker-base-v1 重排模型**取 top 5 进入生成，解决「召回超上下文长度、噪声挤占」问题
- 工程实现：Langchain-Chatchat（Langchain 中文知识问答框架），78 份文件 → 6658 条知识片段

### 模块④：角色化提示词增强模板

按排污许可制的 **6 类角色**（排污单位/生态环境部/省市主管部门/技术评估机构/公众）设计差异化提示词模板，模板要素：角色设定 + 上下文信息 + 指令说明 + 补充输入 + 示例引导 + 输出风格与范围，用 %field%（一级行业）/%subfield%（二级行业）变量做结构化编排。

## 三、实验结论（关键数字）

- **消融实验**（5 模型 × 基线/L-DP/LR-DP/提示词）：LR-DP 比基线平均提升：关键词复现率 +5.90、主题词复现率 +4.40、BLEU +5.02、ROUGE-1 +3.92、ROUGE-2 +4.22、ROUGE-L +3.48、余弦相似度 +2.56 百分点；综合得分最高提升 5.30（ChatGLM4-9b）
- **模型选择结论**：Qwen2.5 系列上提示词增强效果最显著（Qwen2.5-14b 综合得分 83.2%→89.2%）；Baichuan2-13b 与提示词策略有内部知识冲突（略降）
- **角色模板有效性**：ChatGLM4-9b 上「排污标准执行」模板余弦相似度 88.3%，比无模板 LR-DP（77.8%）提升 10.5 百分点；但「排污决策」模板 75.4% 低于基线——复杂推理场景模板仍有优化空间
- 评测体系：关键词/主题词复现率 + BLEU + ROUGE-1/2/L + 余弦相似度，加权综合得分（语义相似权重 0.8）

## 五、可落地的改进方向（按投入产出排序）

### 方向 A：混合检索升级（论文模块③，与迭代 3 规划完全重合，推荐优先）

- Bge 嵌入向量检索 + BM25 双路召回 → 融合（RRF 或加权）
- Bce-reranker-base-v1 神经重排 vs 现有覆盖率重排做对比实验
- 高频干扰词剔除策略用于向量检索前的查询预处理
- **正好关闭 OPEN-DECISIONS 第一在决项**：论文已验证 Bge 路线在同类场景有效，POC 可直接对照论文配置（召回 20 → 重排取 5）
- 本机 RTX 4070 离线建索引（bge-large-zh-v1.5 或 bge-small-zh），服务器 CPU 在线推理（422 片段规模很小，毫秒级）

### 方向 B：角色化提示词增强（论文模块④，低成本高可见度）

- 按 PRD 用户画像设计 4 类角色模板：施工安全员（现场检查要点视角）/ 项目经理（合规责任视角）/ 监理工程师（审查要点视角）/ 编辑·政务人员（条文溯源视角）
- 前端加角色选择（顶栏或首次访问时选择，localStorage 记住），后端按角色注入对应提示词模板
- 论文实测此法在结构化输出场景 +10.5pp 余弦相似度，我们无需训练即可落地，1-2 天工作量

### 方向 C：LoRA 微调（论文模块①②，重投入，可作为毕设深水区亮点）

- 用论文的 ChatGPT 辅助标注法，从 422 条款片段构建建安法规问答数据集（预估 800-1500 条）
- QLoRA 微调 Qwen2.5-7b（RTX 4070 12G 可行，LlamaFactory 工具链论文已验证）
- 对比实验：RAG-only vs RAG+LoRA，用论文的 7 指标评测体系
- 价值：脱离 DeepSeek API 依赖、领域术语对齐；风险：数据构建人力、显存紧张、与 RAG 的增益可能有限（论文中 L-DP→LR-DP 的提升小于 RAG 本身）

### 方向 D：评测体系升级（论文 §4.2，所有方向的基础设施）

- 把 qa_regression 的 14 题扩充为带标准答案的评测集，实现 BLEU/ROUGE/关键词复现率/余弦相似度自动打分
- 每次检索/提示词改动都能出量化对比表（学论文表 5 的消融实验格式，汇报时极有说服力）

## 六、建议

**A + B + D 组合**是当前最优路径：A 是论文与我们迭代 3 的交集（有据可依）、B 是论文中成本最低的独立创新点（角色模板 PRD 里就有用户画像支撑）、D 让改进可量化。C 作为可选深水区，视毕设要求的时间预算再决策。

与指导老师汇报时的对应话术：论文的 LR-DP 框架四模块中，我们已自发实现了 RAG 主链路（含查询重写），改进将围绕「向量检索 + 神经重排（模块③检索增强）」与「角色化提示词（模块④）」两个论文验证有效的方向展开，并以论文的评测体系建立量化对比。
