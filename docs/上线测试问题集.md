# 上线测试问题集（2026-09-20）

> 用途：公网部署后的功能验证 + PRD §12 指标观测（「未找到」误判率 ≤10%）。
> 用法：手机流量访问 `http://8.137.11.193:9000`，逐条提问并按「预期」核对。
> 记录：通过打 ✅，异常打 ❌ 并记下现象（截图 + 时间点），汇总后反馈给开发。
> 注意：首页示例问题已有 6 条（有限空间气体检测/特种作业资格/开工一件事材料/禁限用技术/危大严重缺陷/震后评估分级），本清单全部避开不重复。
