## 3. 一键部署（服务器 PowerShell，管理员）

把 `setup-v7-server.ps1` 也上传到 `C:\Users\Administrator\`（第 1 步方式 A/B 同样操作），然后：

```powershell
cd C:\Users\Administrator
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-v7-server.ps1
```

脚本自动完成 9 步并逐步打印：预检 → 备份旧目录 → 解压（`--strip-components=1`）→ 校验关键文件 → 放 `.env` → venv + 锁定依赖 → 写 `start-server.bat`（`--host 0.0.0.0`）→ 防火墙放行 9000 → 注册开机计划任务 → 启动并轮询 `/api/health`。

**期望末尾输出**：`health: {"status":"ok", ... "docs":37,"chunks":509,"hybrid":{"ok":true,"backend":"onnx-int8","n_chunks":509}}`，且 `llmConfigured=true`（因为已放 `.env`）。

> 若 `llmConfigured=false`：检查 `C:\jianan\.env` 是否就位、`LLM_API_KEY` 是否非空。
> 若 hybrid `ok=false`：多半是 VC++ 运行库没装或 `model_int8.onnx` 缺失。
> 若 60 秒内 health 未就绪：看 `C:\jianan\server.log`。
