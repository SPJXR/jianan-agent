## 三、评分标准（省赛/国赛同表，100 分制加权）

| 维度 | 权重 | 细分 |
|---|---|---|
| **AI 技术深度** | **35%** | 大模型集成质量 8%（选型/Prompt 精巧/输出稳定）、**Agent/工作流设计 8%**（规划、工具调用、自主决策）、**RAG 技术应用 6%**（检索策略合理、生成质量显著提升）、多模态 5%、**AI 安全与可控 4%**（安全/可解释/过滤/兜底）、MCP/Function Calling 工具集成 4% |
| 创新性 | 25% | 选题创新 10%、技术方案创新 8%、交互模式创新 7% |
| 前端工程质量 | 10% | **TypeScript 规范 4%**、组件化与架构 3%、性能优化 3% |
| 实用性 | 10% | 场景真实性 5%、方案有效性 5% |
| 用户体验 | 10% | UI/响应式/设计系统 4%、前端交互 3%、**AI 交互（流式渲染、思考状态可视化、错误边界）3%** |

## 四、项目现状 × 评分表差距矩阵（基于本地仓库实测）

**项目现状**（2026-11-15 核对）：FastAPI 后端 + **原生 HTML/CSS/JS 前端**（`web/` 仅 4 文件，无 package.json/无 TS/无框架）；OpenAI 兼容流式接口（DeepSeek）；混合检索 BM25+向量、两阶段改写、逐字引用契约、时效状态、拒答兜底、SSE 流式、角色化提示词、62 题规则断言评测、55 次 Git 提交；**无远端仓库**、`.env` 未入库（有 `.env.example`）；历史公网演示地址 `47.109.98.111:9000` / `8.137.11.193:9000`（需确认仍可用）。

| 评分区 | 现状证据 | 粗估 | 补强动作（按 ROI） |
|---|---|---|---|
| 大模型集成 8% | 契约规则 1~6、角色化提示词、流式、跨日漂移治理；但单模型 API 直连 | 5-6 | 展示 Prompt 演进史（v1→v3 逐字节守卫）、多模型可配置（已有 config） |
| **Agent/工作流 8%** | 仅「弱命中→改写→并集合并」两阶段条件触发，无规划/工具调用 | 1-2 | **最大增量点**：把既有条件触发链路显性化为 Agent 工作流（plan→retrieve→verify→answer），配前端「思考状态可视化」；对应三篇分析里的 P1 条件触发 agentic 候选 |
| RAG 6% | 混合检索 + 时效双管 + 相邻注入 + 逐字引用 + 9 篇论文证据链的评测体系 | 5-6（强项） | 技术文档重点写检索策略与四重证据链；演示 62 题 48/54 与引用溯源 |
| 多模态 5% | 无 | 0 | 可选：现场「拍照/上传现场隐患图→检索条款」轻量图片入口（成本高、需 POC）；或诚实不追 |
| **AI 安全可控 4%** | 拒答契约、未收录/下架转拒答、逐字引用溯源、MIN_COVERAGE 兜底、引用白名单自检、弃答路径审计 | **4（满分级）** | 做成演示亮点：ALCE/A-MEM 学术对照 + 「答不出就承认」 |
| 工具集成 4% | 无 Function Calling / MCP | 0-1 | 低成本：把 `hybrid_search`/`docs_meta`/`get_chunk_context` 包成工具接口并在文档里显式呈现（项目本就具备全部原子能力） |
| 创新性 25% | 垂直法规 + 逐字可核查 + 时效台账 + 9 篇论文驱动的评测体系；交互为 SSE+引用卡片+角色切换 | 16-19 | 技术文档把「规则断言 vs NLI/judge」取舍、四次 POC 否决写成方法创新 |
| **前端工程质量 10%** | 原生 JS，无 TS/组件化/构建；但代码有注释、结构清晰、响应式 CSS | 3-4 | **硬缺口**：赛道明确「现代前端框架为基础」。若参赛需迁移 Vue3/React（可用 Vite 渐进改造，保留 SSE 流式与引用卡片），或至少补 TS+组件化 |
| 实用性 10% | 34 份真实法规、现场工人真实问答、已部署公网使用 | 8-9 | 用真实提问日志/截图、ACCEPTANCE 验收记录佐证 |
| 用户体验 10% | 流式输出、引用来源卡片、角色切换、历史侧栏、移动端适配；无思考状态可视化 | 6-7 | 补「检索中/改写中/证据收集」状态可视化（现成 SSE status 事件已发出，前端展示即可） |
| 社会价值 10% | 建筑施工安全、法规时效与防幻觉、可推广到其它垂直法规库 | 7-8 | 写清安全生产社会价值 + 垂直行业复制路径 |

**粗估总分 ~55-62/100**：强在 RAG/安全/实用性/学术证据链，弱在**前端框架与 TS（硬要求）、Agent/多模态/工具集成（17 分空间）、公开仓库与竞赛材料**。

3. **公开仓库**：当前 `git remote -v` 为空——需新建 GitHub/Gitee Public 仓库并推送；**55 次细粒度提交是原创性优势**（官方明确禁止 initial commit 一次性全量）。
4. **密钥合规**：`.env` 已 gitignore、仅 `.env.example` 入库 ✅；推送前仍需全仓扫描（含 `docs/screenshots/`、部署包 `.tar.gz`、历史提交中的配置文件）。
5. **原创性**：仓库有《原创性与第三方资源清单.md》可直接用于答辩/文档；引用 9 篇论文需规范标注（毕设素材已有 APA 习惯）。

7. **材料完整性**：视频 5-8 分钟 1080p 普通话、PDF ≤30 页、README 四项、环境变量模板、依赖清单——**提交后不得修改**。
