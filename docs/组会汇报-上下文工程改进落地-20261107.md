### 2.4 挖出的真 bug：兜底判据与向量路的实现脱节

- **症状**：PM-02「证书快到期了怎么办理延续」跨两版知识库稳定失败——**引用卡片展示着延期复核条款原文，答案却说"知识库中未找到"**，自相矛盾。
- **根因**：兜底判据那行代码诞生于纯 BM25 时代，向量检索引入后没跟着改——向量块覆盖率恒为 0（设计如此），"向量语义救回正确块但改写词覆盖率恰好持平"的场景下判据被归零，误触发兜底。**实现偏离了自家 ADR-002 契约"兜底判据维持 BM25 主判据"**。
- **修复**：一行取两判据较大值。62 题逐题 ok 零回退、唯一变化即 PM-02 修复，46/54。
- **体会**：这题线上挂着两个多月没人报——因为引用卡片看起来"是对的"。**用户侧最伤信任的不是答不出，而是界面自相矛盾**。

## 四、第 3 期开项：两项生成侧改进落地（26b023f + 4053bb0）

### 4.1 3.3 时效状态进上下文（11-04）

- **问题**：人工核定的法规时效结论（现行/试行/未生效/废止）此前只作用于检索降权和前端徽章，**LLM 从来看不到**——「指南生效了吗」答"无法判断"，两道版本取舍题直接拒答。
- **修法**：上下文片段头注入〔状态〕行 + 一句不触碰拒答契约的说明；未核定语料零标注零改动（输出逐字节一致）。
- **效果**：A/B 探针从"无法判断以哪个为准，建议咨询发布机关"变为"**应以试行版为准，征求意见稿未生效**"；4 题专项 2/4 → 3/4+1 题抖动观察（已如实标注）。

### 4.2 3.1 相邻条款定向注入（11-07，本周收官）

- **问题**：法规长列举被分块切断后，检索只命中前半块，LLM 的清单天然不完整——PM-06 只能列出 12 类特殊建设工程中的前 5 类。
- **修法**：块尾断裂信号（`，、；：`，全库仅 10% 块命中）触发注入下一块逐字全文（上限 3 块、去重），**相邻块不进引用编号体系**——引用卡片无对应块，杜绝"引用了看不见的块"的幻觉通道。
- **效果**：PM-06 十二项列全；62 题 46/54 → **48/54**（PM-06、PM-11 双修复），边界题 2/3 → 3/3。
- **计划假设被实测修正**：原定"top-3 主证据断裂即注入"，实测目标断裂块排第 9——改为按断裂信号触发，更准也更省。
- **收益面诚实记录**：探测发现"问后半内容"的问法多数会直接召回 next 块（注入无增量），真实收益面是"问整体清单、条目在列举后半"的窄场景。相邻注入是断裂的**兜底**而非根治，不为凑专测组造题。

## 附：本轮三个可以写进总结的方法论点

1. **先证明有病再吃药**：本周三个计划方案（2.1 自适应装配、2.2 截断、2.4 关键词行）被实测否决——POC 花半天，省下的是永久性的提示词复杂度和回归面。"已验证无需做"和"做了没效果"一样是正经结论。
2. **同 KB stash 对照 + 逐题 ok 零互换**：62 题 A/B 不看总分看逐题——改前对照组用 git stash 在同一知识库上跑，逐题 ok 零互换才能宣称"零回归"，总分持平掩盖不了的互换会被逐题对比暴露。
3. **归因靠对照实验，不靠猜**：GOV-06 翻转后先怀疑自己的改动，同片段有/无注入各跑一组——改前形态同样复现不出，才能把锅判给服务端漂移。A/B 探针是排查 LLM 系统里"哪一层变了"的手术刀。
