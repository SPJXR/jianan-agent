## 三、部署步骤（管理员 PowerShell）

```powershell
# 1) 上传：部署包 + .env（.env 含 API Key，单独上传，绝不入包/公开仓库）
#    本机 Git Bash：
#    scp deploy-pkg/jianan-app-v7-20261115.tar.gz Administrator@<IP>:"C:/Users/Administrator/"
#    scp .env Administrator@<IP>:"C:/Users/Administrator/env-v7.txt"

# 2) 备份现网（回滚用），再解压
mkdir C:\jianan-v7 -Force
tar -xzf C:\Users\Administrator\jianan-app-v7-20261115.tar.gz -C C:\jianan-v7 --strip-components=1
#    ⚠ --strip-components=1 必须带，否则嵌套 jianan-app/ 目录会跑旧代码

# 3) 放置配置
move C:\Users\Administrator\env-v7.txt C:\jianan-v7\.env

# 4) 依赖（VC++ 运行库若未装，先装 vc_redist.x64.exe）
python -m venv C:\jianan-v7\.venv
C:\jianan-v7\.venv\Scripts\python.exe -m pip install -r C:\jianan-v7\requirements.lock

# 5) 启动与验证
cd C:\jianan-v7
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 9000
curl http://127.0.0.1:9000/api/health
#    期望：status=ok、llmConfigured=true、hybrid.ok=true、n_chunks=509
```

切换流量时保留旧目录 `C:\jianan`，确认 health 与关键问答后再改反向代理/安全组指向；出问题直接切回旧目录并重启。HTTPS 反代、每日备份、日志轮转见包内 `deploy/README-ops.md` 与 `deploy/Caddyfile`。
