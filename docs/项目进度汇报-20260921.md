## 三、本次汇报重点：上线后发现并解决的问题（最有价值的部分）

产品上线不是终点。通过真实用户测试，我们暴露并修复了 4 类检索缺陷，这个过程验证了「上线测试问题集 → 定位根因 → 修复 → 回归」的工程闭环。

### 缺陷 1：检索排序失真（第一轮修复，09-20）

- **现象**：「特种作业人员报名条件」答非所问
- **根因**：BM25 加分未归一化，LIKE 召回块 bonus 权重失衡
- **修复**：bonus 归一化 + 系统提示词要求 LLM「先通读全部片段再作答」
- **验证**：11 道测试题全部 top 命中正确文档

### 缺陷 2：多轮追问检索稀释（第二轮修复，09-21）

- **现象**：按序号连问时（A4→A3、A9→A8），后一问答非所问
- **根因**：上一问的词被拼进 query 参与相关度计算，摊薄了当前问题的信号
- **修复**：上下文词只用于扩召回，覆盖率只按当前问题计算；连带修复了「先截断后过滤」的顺序错误和 LIKE 泛词截断问题

### 缺陷 3：口语化词汇鸿沟（本轮核心升级，09-21）

- **现象**：「工地上挖坑底下干活有啥危险」查不到（文档里叫「有限空间作业」）；「密目网着火」查不到（文档里叫「阻燃」）
- **根因**：BM25 字面匹配无法跨越口语与法规术语的词汇鸿沟——这正是工友真实问法与法规文本之间的天然差距
- **修复**：**两阶段检索**——弱命中时先由 LLM 把口语问题改写为法规术语，再检索一次择优采纳；强命中不付这次代价，控制延迟与成本
- **效果**（线上实测）：「挖坑底下干活」→ 正确命中《有限空间作业指南》中毒/窒息/爆炸/淹溺风险及「先通风、再检测、后作业」原则

## 四、当前产品能力清单

**已上线功能**：

- 基于 34 份文档（422 条款片段）的即时问答，SSE 流式输出
- 每条回答附引用 chip → 点击展开条款**逐字原文** + 前后相邻条款
