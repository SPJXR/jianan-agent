## 一、本轮做了什么（一句话）

参考车蕾论文的「角色化提示词增强模板」（模块④），按 PRD 用户画像将回答层升级为 **5 套角色模板**（通用 / 安全员 / 项目经理 / 监理工程师 / 政务编辑），用户选择身份后，同一问题按角色获得不同侧重的回答；检索层零改动，全量回归测试通过。

## 二、核心成果

| 项 | 说明 |
|----|------|
| 角色设计依据 | 论文模块④模板三要素（角色设定/指令说明/输出风格）+ 本项目 PRD 四类用户画像 |
| 安全员视角 | 优先给出可对照执行的检查要点与「必须/禁止/不得」强制性规定、隐患判定口径 |
| 项目经理视角 | 优先说明管理流程、审批报审要求、建设/施工/监理各方责任划分、罚则主体 |
| 监理工程师视角 | 优先给出审查验收要点、严重缺陷/重大隐患判定口径、整改指令条款依据 |
| 政务编辑视角 | 引用条款写明文件名称与条款位置，术语按法规原文定义，便于行文直接引用 |
| 角色效果抽样 | 同一问题「桩头凿除有什么规定」：通用版 182 字直答禁限规定；项目经理版 353 字，补充替代工艺与条款定位 |
| 工程成本 | 无需训练、无新依赖；检索层（V4 混合检索）零改动，全量回归原样通过 |

## 三、产品生命线保护（本轮重点设计）

角色化只改变「表达侧重」，**不触碰回答契约**：

- 契约规则 1~6（逐字引用、标注编号、诚实拒答、越界拒答）在所有角色模板中**逐字保留**，回归测试对 6 条关键句逐句断言；
- 通用（default）模板与现网系统提示词**逐字节一致**，不选角色的用户行为与 V4 完全相同；
- 非法/缺失的角色参数自动回退通用模式，旧版本前端不受影响。
